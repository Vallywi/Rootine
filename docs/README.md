# Rootine Documentation

Rootine is a Pomodoro focus web app. While you focus, a plant grows. Finish the session and it joins your garden. Give up and it withers.

**Current stage: MVP code is written (see the root `README.md` for how to run it). The plans here describe what it is built to do.**
